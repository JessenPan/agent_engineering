## 理论重点

覆盖整个生命周期：离线任务集、基准与回归；线上采样评估、用户反馈、执行轨迹、效果趋势、评估器校准、线上实验，以及 bad-case 收集、归因、复现与修复。

Rubrics（评分细则）明确纳入本方向：在 [07.1](./index.html#subtopic-07-1) 学习评价维度、各档分数的判定描述、通过条件、严重失败条件和审核示例；在 [07.6](./index.html#subtopic-07-6) 学习人工与模型共用细则、分歧复核、版本管理和独立样本验证；在 [07.5](./index.html#subtopic-07-5) 将典型失败与评分器误判关联为判定示例及回归用例。评分细则用于评价任务表现，学习单元的完成标准用于记录学习进度，两者分别管理。

线上评估可以异步执行；上线后固定数据集回归仍是离线评测。线上评分不等同于 A/B 实验。服务可用性、并发、延迟与故障恢复主要归第十类。

## 实践起点

串联固定评测集、模拟线上采样、执行记录、失败归因和回归测试。实际生产案例与模拟案例分开记录，工具调用成功不等于任务成功。

先编写任务专属的评分细则，并将环境结果检查与主观质量评分分别报告。用校准样本改进细则及示例，再用独立保留样本检查人工与模型的一致性和严重失败误判。上述做法是待实验验证的工程计划，具体资料与练习见各子方向记录。

# 综合实践项目

HTML 入口：[综合实践](./index.html)。已建立 [Agent Learning Lab](./agent-learning-lab/index.html) 的阶段计划，尚未开始实现。

这里用于跨越多个学习分类的练手项目，例如把工具调用、知识检索、状态管理、评估与安全控制组合起来。

每个项目使用独立目录，说明目标、关联分类、权威资料与论文、参考 GitHub 项目、运行环境、验证方法和实际结果。

单一子方向的练习及实验记录放在所属子方向中；同一学习方向内跨子方向的项目放在该方向的 `projects/`。本目录只收录跨学习方向的项目，不再汇总各方向的专项练习。根目录独立项目位置以用户明确选择为准。

当前包含一个综合实验计划，各分类也有独立练习计划；尚无已运行项目或实验结果。
